## 문제

커뮤니티 토큰 런치 화면은 가격과 거래량을 빠르게 보여주지만, 창작자 배정,
베스팅, 유동성 원금의 통제 경로, 추가 민팅·정지·블랙리스트·세금 같은 관리자
권한, 홀더 집중도, 컨트랙트 소스 상태, 인덱서 신선도는 여러 화면과 컨트랙트를
직접 읽어야 드러납니다. 사용자는 서로 다른 출처와 확실성을 가진 사실을 하나의
“안전” 배지로 오해하기 쉽습니다.

## 해결책과 독창성

Forge는 안전을 약속하거나 점수로 축약하지 않습니다. 고정 템플릿 런치,
창작자 물량의 온체인 베스팅, LP 원금 보관, 홀더 분포, 관리자 권한, 소스 및
데이터 신선도를 각각의 사실과 출처로 보여줍니다. 확인되지 않은 항목은
`데이터 수집 중` 또는 부재로 남기고, 로컬에서만 검증한 사실을 GIWA 라이브
사실처럼 승격하지 않습니다.

## 왜 GIWA인가

Forge의 첫 사용자와 인터페이스는 한국어 우선입니다. GIWA는 EVM 호환성,
한국어 빌더 문서, 소비자 지갑 경로를 함께 제공하므로 기존 Solidity 안전
경계를 유지하면서 한국 사용자가 위험 사실을 결정 시점에 확인하는 제품을
검증하기에 적합합니다. 이것은 독점적인 체인 기능 주장이나 업비트 거래지원
경로 주장이 아닙니다. 실제 GIWA 배포, Wallet 호스트 연동, 외부 사용자 검증은
아직 남은 마일스톤입니다.

더 긴 서술은 [`why-giwa.md`](why-giwa.md)를 사용합니다.

## 구현 수준

고정 공급 토큰, 창작자 베스팅, 영구 LP 보관, 런치 팩토리, 타입이 지정된
트랜잭션 의도, 이벤트 소싱 인덱서, 지갑 UI, 공개 읽기 전용 빌드를
구현했습니다. 로컬 Anvil 수직 경로는 런치, 결정론적 테스트 계정 12개의 매수,
정확액 승인, 매도, 13건의 거래 인덱싱, 새로고침 복구를 검증했습니다. 이
12개는 자동화 테스트 계정이며 사용자 지표가 아닙니다.

GIWA Sepolia에는 명시적 `USE_SELF_HOSTED_TEST_AMM=true`로만 선택되는
자체 정률곱 테스트 AMM 경로를 추가했습니다. 어댑터와 풀은 체인 ID `91342`를
강제하고 `isTestOnly()`를 유지합니다. 기본 외부 V2 경로는 계속 비활성입니다.
이 경로는 아직 브로드캐스트되지 않았고 감사 또는 메인넷 준비를 뜻하지
않습니다.

## 기술 완성도

현재 GASOK 변경 기준으로 Foundry 전체 69/69가 통과했습니다. 동일한 GIWA
흐름 테스트 7개는 공식 public RPC의 읽기 전용 포크에서도 7/7 통과했고,
배포 모드 분기도 포크에서 1/1 통과했습니다. 이는 로컬 EVM 시뮬레이션이며
온체인 트랜잭션을 만들지 않았습니다.

월렛 컨테이너 레이아웃 변경은 web Vitest 75/75와 Playwright motion smoke
2/2를 통과했습니다. 최종 후보 작업 트리의 전체 검증은 Vitest 151/151,
Foundry 69/69, 전체 Playwright 3/3, strict typecheck, 린트, ABI·빌드,
매니페스트, 시크릿 스캔, 의존성 감사, 보안 헤더, fuzz·invariant, 다중
뷰포트 QA를 통과했습니다. 독립 보안 감사는 아직 받지 않았습니다.

## GIWA Wallet 내 탑재 가능성

`?embed=wallet`은 390px 단일 컬럼, 중복 사이트 내비게이션과 지갑 연결 UI
제거, 내부 링크 query 보존, reduced-motion 대응을 검증한 wallet-container
레이아웃 프로토타입입니다. 공개 모드에서는 연결·견적·승인·매수·매도 실행이
모두 차단됩니다.

이는 GIWA Wallet 호스트 통합 완료가 아닙니다. 실제 SDK 또는 브리지,
계정·세션 전달, 보안 검토, 배포 URL, GIWA의 인앱 승인 증거는 없습니다.

## 시장성과 초기 사용자

한국어 우선 위험 공개 문제와 작동하는 읽기 전용 데모는 있지만, 외부 사용자,
리텐션, TVL, 거래량, 전환율, 지불 의사 증거는 아직 없습니다. 실제 GIWA
Sepolia 배포와 사전 점검 뒤 5~10개의 독립 지갑 운영자를 동의 기반으로
모집해 위험 사실 이해도, 과업 완료·중단, 실패 지점을 함께 집계하겠습니다.
자동화, 배포자, 팀 통제 지갑은 제외합니다.

지갑 주소와 트랜잭션 해시는 공개 저장소나 피치덱에 올리지 않습니다.
온체인 동작 자체가 공개라는 사실을 먼저 알리고, 원시 증거가 꼭 필요하면
별도 동의를 받아 비공개로 보관합니다. 초대와 수집 경계는
[`pilot-invite.ko.md`](pilot-invite.ko.md)를 따릅니다.

## 팀과 실행 역량

현재 운영 모델은 AI 보조 개발·리뷰 도구를 사용하는 솔로 빌더입니다. AI
도구는 팀원이 아니며 내부 테스트와 AI 리뷰는 독립 감사가 아닙니다. 지원자는
다음 항목을 직접 입력해야 합니다.

- `[지원자 입력 필요]` 실명과 역할
- `[지원자 입력 필요]` 관련 경력과 검증 가능한 링크
- `[지원자 입력 필요]` 주당 투입 시간과 프로그램 참여 가능성
- `[지원자 입력 필요]` 개인 또는 법인 지원 주체와 연락처

GASOK 지원은 독립 스마트컨트랙트 감사, GIWA 유동성 경로 검토, Wallet 호스트
통합, 두 번째 엔지니어링·리뷰 기여자 확보에 우선 사용하고자 합니다.

## 수익 모델

현재 수익과 지불 의사는 검증되지 않았습니다. 프로토콜에는 상한이 있는 향후
런치 생성 수수료 설정이 있지만 현재의 시장 증거로 수익을 예측하지 않습니다.
파일럿에서 런처의 지불 의사와 사용자 신뢰·완료율을 확인한 뒤, 공개된 생성
수수료와 운영 비용을 검증하겠습니다. 거래지원, 토큰 가격 상승, 숨겨진
거래세를 수익 모델로 제시하지 않습니다.

1. 정확한 제출 커밋에서 전체 검증을 다시 실행합니다.

3. 명시적 테스트 전용 스택을 브로드캐스트한 뒤 주소, 소스, bytecode를
   익스플로러에서 검증합니다.
4. 런치·견적·매수·매도 영수증과 인덱서 정합성을 대조합니다.
5. 5~10개 독립 지갑 파일럿의 성공과 실패를 동의 기반으로 집계합니다.
6. 독립 감사와 GIWA Wallet 호스트 통합 검토를 진행합니다.
