# Forge GIWA Sepolia 파일럿 초대문

상태: **초안 — 실제 GIWA Sepolia 배포와 운영자 사전 점검 전에는 발송하지
않습니다.**

## 짧은 초대문

> 안녕하세요. 커뮤니티 토큰의 위험 정보를 한눈에 보여주는 Forge의 GIWA
> Sepolia 테스트에 참여해 주실 분을 찾고 있습니다. 테스트넷 전용이며 쓰는
> 자산은 실제 가치가 없습니다. Forge는 감사 전 프로토타입이고 GIWA·두나무·
> 업비트의 공식 서비스가 아니며, 상장·수익·안전을 약속하지 않습니다.
>
> 참여자는 위험 정보 화면을 읽고 테스트넷 동작 1개를 수행한 뒤 짧은 피드백을
> 남깁니다. 시드 문구나 개인 키는 절대 요구하지 않습니다. 참여 결과는 동의한
> 최소 범위에서만 집계하며 지갑 주소와 트랜잭션 해시는 공개하지 않습니다.
> 참여를 원하시면 이 안내를 읽은 뒤 운영자에게 “동의하고 참여합니다”라고
> 답해 주세요.

## 참여 절차

1. 운영자가 제공한 정확한 테스트 URL, 네트워크가 `GIWA Sepolia`, 자산이
   테스트넷 전용인지 확인합니다.
2. 토큰 상세 화면에서 위험 사실을 읽고, 가장 중요하다고 느낀 사실 하나를
   고릅니다.
3. 실제 배포와 사전 점검이 끝난 경우에만 지정된 테스트넷 동작 하나를
   수행합니다. 문제가 보이면 서명하지 말고 중단합니다.
4. 완료 여부, 막힌 단계, 선택한 위험 사실, 선택적 의견 한 줄을 전달합니다.
5. 언제든 참여나 데이터 사용 동의를 철회할 수 있습니다.

## 참여자에게 다시 알릴 사항

- 테스트넷 자산은 실제 가치가 없으며 구매·투자 대상이 아닙니다.
- Forge는 감사 전 소프트웨어입니다. 오류나 자산 손실 가능성이 있습니다.
- Forge는 GIWA, 두나무, 업비트의 공식 서비스가 아닙니다.
- GASOK 참여나 선정은 업비트의 디지털 자산 거래지원과 무관합니다.
- 수익, 상장, 보상, 안전을 약속하지 않습니다.
- 테스트넷 온체인 동작 자체는 공개 원장에 남습니다. 운영자는 참여자의 주소나
  트랜잭션 해시를 공개 자료에 다시 연결하거나 게시하지 않습니다.
- 운영자는 시드 문구, 개인 키, 원격 지갑 제어, 실명, 연락처 공개를 요구하지
  않습니다.

## 동의 기반 최소 지표

운영자는 다음 항목만 수집합니다.

- 임의 참여자 코드(`T01` 등)와 동의 시각;
- 모집 경로와 인센티브 제공 여부;
- 시도한 과업, 완료 여부, 걸린 시간대, 막힌 단계;
- 선택한 위험 사실과 선택적 피드백 요약;
- 테스트한 제품 커밋과 배포 매니페스트 버전.

독립 지갑 수를 확인하기 위해 원시 지갑 주소나 트랜잭션 해시가 꼭 필요하다면
별도 동의를 먼저 받고 운영자만 볼 수 있게 보관합니다. 온체인 트랜잭션 해시를
공개하면 지갑 주소를 역추적할 수 있으므로 주소와 해시는 저장소, 피치덱, 공개
보고서, 공개 채팅에 올리지 않습니다. 지원서에는 성공과 실패를 포함한 집계
수치만 쓰고, 원시 증거는 해당 지원서의 개인정보 조건과 참여자 동의가 모두
허용할 때에만 비공개 검증용으로 제공합니다.

## 운영자 발송 전 체크

- [ ] 실제 GIWA Sepolia 배포 주소와 영수증을 검증했다.
- [ ] 테스트 과업과 중단 조건을 정했다.
- [ ] 테스트넷 자산만 사용하고 실자산 요청은 없다.
- [ ] 1명당 1개 독립 지갑만 집계하며 자동화·팀·배포자 지갑은 제외한다.
- [ ] 인센티브가 있다면 조건과 금액을 먼저 공개했다.
- [ ] 원시 주소·트랜잭션 해시의 접근 권한과 삭제 시점을 정했다.
- [ ] 성공 사례뿐 아니라 중단·실패도 동일하게 집계한다.
